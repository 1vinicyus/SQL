# SQL

Este repositório contém tabelas, scripts e comandos SQL para praticar conceitos de Banco de Dados.
Aqui você encontrará exemplos de:
- Criação de tabelas (`CREATE TABLE`)

- Inserção de dados (`INSERT`)

- Consultas (`SELECT`)

- Atualizações (`UPDATE`)
  
- Exclusões (`DELETE`)
  
- Relacionamentos entre tabelas
  
- Chaves primárias e estrangeiras
  
- Exercícios práticos de modelagem de dados
  
 
O objetivo deste material é auxiliar no aprendizado e na prática de SQL e Banco de Dados Relacionais
